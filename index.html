On-device speech for SpeechLP

Converted a wav2vec2 phoneme-recognition model to Core ML so SpeechLP can score a child's pronunciation on the phone, with no recording leaving the device. The standard PyTorch → ONNX → Core ML route failed; tracing the module and declaring a 30-second runtime input range worked. A public rebuild benchmarks FP32, FP16, and INT8 packages, and FP16 delivers half of FP32's size with identical output tokens.

🌿 About

I like the whole loop: the interface a person touches, the plumbing behind it, and the measurement that says whether it worked. The most useful thing I learned at ParagraphAI is that a feature is not done when it renders — it is done when you can tell whether it helped. I instrument what I build.

Before software I spent six years on a fixed income trading desk, which is where I started automating manual reporting with code. That instinct — find the repetitive thing, remove it — carried straight into product work.

At ParagraphAI I also did the marketing work engineers usually avoid: brainstorming content, filming social videos, and a stretch of shoots inside the company's purple penguin mascot. Talking to a camera is not the same as talking to a customer, but it removed the fear of both.

Off the clock: badminton, biking, hiking, baking, cooking, ukulele, and League of Legends.
