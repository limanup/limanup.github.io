On-device speech for SpeechLP

2025

SpeechLP is the team's speech-therapy app for kids: a child says a word and the app scores the pronunciation. A server round trip is too slow for that feedback loop, and it would mean uploading a recording of a child — so the model had to run on the phone. The standard PyTorch → ONNX → Core ML route failed four times; the path that worked traces the module and declares a 30-second runtime input range. A public rebuild of the conversion benchmarks FP32, FP16, and INT8 on a public checkpoint; FP16 is the one that ships — half of FP32's size, same output tokens.

  • Python
  • PyTorch
  • coremltools
  • Core ML
  • iOS

🌿 About
